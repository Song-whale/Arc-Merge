# Arc Merge

Arc Merge 是一个在浏览器中运行的 Arcaea `st3` 存档合并工具。它可以读取多个存档，
逐个谱面比较成绩，保留最高记录，并生成新的 `st3` 文件。

## 原理

Arcaea 的 `st3` 文件是 SQLite 数据库，成绩主要保存在 `scores` 和 `cleartypes`
表中。每条谱面记录由 `songId`、`songDifficulty` 和 `ct` 确定。

合并时，工具会：

1. 读取每个上传存档中的成绩记录。
2. 按谱面主键汇总所有记录。
3. 对同一谱面保留分数最高的记录。
4. 同步保留该记录的判定数、`clearType` 和日期。
5. 将结果写入 SQLite 数据库并执行完整性检查。

所有解析和合并都在浏览器本地通过 SQLite WASM 完成，文件不会上传到服务器。

## 功能

- 合并两个或更多 `st3` 存档。
- 逐谱面保留最高分。
- 分别处理不同难度和控制类型。
- 预览、搜索和筛选合并后的记录。
- 导出新的 `st3` 文件。

## 使用

1. 备份原始存档。
2. 选择两个或更多 `st3` 文件。
3. 点击“合并”并检查结果。
4. 导出新的 `st3` 文件。

## 查找存档文件

Arcaea 的成绩存档通常是没有扩展名的文件 `st3`，不是整个游戏安装目录。

### Android

常见路径为：

```text
/data/data/moe.low.arc/files/st3
```

普通文件管理器通常无法访问该目录。可以在已获得相应权限的设备上使用支持访问应用数据的
文件管理工具，将该 `st3` 文件复制到其他目录后再上传。不要直接修改或覆盖原文件。

如果没有权限访问应用数据，可以先使用设备备份工具或现有存档导出工具获得 `st3` 文件。

### iOS

可以使用能够浏览 App 数据容器的备份或文件管理工具，找到 Arcaea 的应用数据并导出
名为 `st3` 的文件。具体路径会因系统版本、工具版本和设备而不同。

### 模拟器

Android 模拟器中的应用数据通常位于模拟器实例的磁盘镜像内，需要使用模拟器提供的文件
管理或 root 功能导出 `st3`。

上传前建议将原文件额外复制一份，并确认所选文件确实位于 Arcaea 的应用数据目录中。

## 本地运行

需要 Node.js 22.12 或更高版本。

```bash
npm install
npm run dev
npm test
npm run build
```

合并逻辑位于 `src/core/st3.ts`，网页界面位于 `src/App.tsx`。

## 范围

本工具处理 `st3` 成绩数据库，不处理账号、解锁和游戏设置文件。若存档结构无法被安全
识别，工具会停止合并并显示错误。
